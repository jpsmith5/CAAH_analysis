# CAAH Molecular Signature

**Related to Figure 6.**

This section describes the derivation of the CAAH 10-gene signature from mouse scRNA-seq data and its evaluation by ROC analysis and comparison to the CKD273 urine proteomics classifier.

The CAAH signature captures transcriptional remodeling specific to RAAS axis suppression in renin-lineage cells: ECM deposition, lysosomal stress, oxidative defense, and HIF-target activation.

### 10-gene CAAH signature (mouse)

```
Clu, Lrp2, Lamp2, Col4a2, Spink1,
Wfdc2, Pax8, Lyz2, S100a9, Cdh13
```

Human equivalents used for cross-species validation:

```
CLU, LRP2, LAMP2, COL4A2, SPINK1,
WFDC2, PAX8, LYZ, S100A9, CDH13
```
