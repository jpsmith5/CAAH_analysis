# Metabolic Pathway Analysis

**Related to Figure 3.**

This section scores and compares five metabolic pathways — OXPHOS, glycolysis, TCA cycle, fatty acid oxidation (FAO), and the pentose phosphate pathway (PPP) — across the <i>Ren1<sup>c+/-</sup></i> knockout and captopril-treated SMMHC-<i>Cre</i><sup>ERT2</sup> models. The analysis builds on the Seurat objects produced in sections 3 and 4.

### Steps

1. [Metabolic gene sets and functions](5A.Metabolic_Functions.md) — define OXPHOS, glycolysis, TCA, FAO, and PPP gene lists; load Hallmark gene sets from MSigDB; define `calcMetabolicScores` and `calcStatistics`
2. [Score metabolic pathways](5B.Score_Metabolic_Pathways.md) — apply UCell scoring across both models, run Wilcoxon rank-sum tests, compute Cohen's d effect sizes, and export results
3. [FAO sub-signature decomposition](5C.FAO_Decomposition.md) — split FAO genes into transport/CPT1, mitochondrial β-oxidation, and peroxisomal sub-groups; score each with UCell; compute per-sub-group effect sizes and gene-level dot plots
